 NexusAI — Modern Business Landing Page

> **Skyelex Internship — Task 02 Submission**  
> A sleek, high-converting, fully responsive landing page built for a fictional technology product.

---

 Project Overview

**NexusAI** is a modern SaaS technology landing page designed to introduce an AI productivity platform, communicate its core value proposition, display features and benefits, highlight customer testimonials, and answer common questions—all while encouraging user engagement through strategic Calls to Action (CTAs).

---

Features Implemented

- **Header & Navigation:** Sticky glassmorphism header featuring smooth navigation links, primary CTA, and a responsive mobile hamburger menu.
- **Hero Section:** Dynamic headline, high-impact subtitle, primary & secondary action buttons, and product visual preview.
- **Product Introduction:** Concise overview establishing the core problem solved by the platform.
- **Features Section:** Responsive card grid highlighting real-time analytics, automated workflows, and enterprise security.
- **Benefits Section:** Key metric callouts emphasizing time savings and conversion gains.
- **Testimonials Section:** Social proof cards showcasing user reviews and credentials.
- **Interactive FAQ Accordion:** Clean, expandable Q&A section driven by vanilla JavaScript.
- **Call-to-Action (CTA) Banner:** Vibrant conversion section driving user signups.
- **Professional Footer:** Multi-column navigation links, legal links, and copyright details.
- **Fully Responsive & Accessible:** Built mobile-first using CSS Grid and Flexbox with media queries for all viewports.
- **Hover & Micro-interactions:** Smooth CSS hover states, card elevations, and button transitions.

 Tech Stack

- **HTML5:** Semantic element structure (`<header>`, `<main>`, `<section>`, `<footer>`).
- **CSS3:** Custom properties/variables, CSS Grid, Flexbox, media queries, keyframe transitions, and dark-mode styling.
- **JavaScript (ES6):** DOM manipulation for the mobile menu toggle and dynamic FAQ accordion interactivity.
